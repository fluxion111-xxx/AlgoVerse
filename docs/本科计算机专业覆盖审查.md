## 此前的实测记录

本地在 RTX 5060 Laptop GPU 的 ANGLE/D3D11 后端和 SwiftShader 上通过同一个 WebGL2 像素断言。测试读取透视 UV、底色 sRGB 解码和材质 G/B 通道。完整 PBR 光照尚待实测。

用 Chrome 对同一组实拍素材的 24 帧做 AVC 与 VP9 各三档编码和解码。目标 280 kbit/s 时，AVC 实得 281.20 kbit/s、36.70 dB，VP9 实得 245.50 kbit/s、37.62 dB。PSNR 使用 RGB 全通道。输入为已压缩的 [MDN flower.mp4](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video)，SHA-256 为 `0cd83d944a6ca7822b4a8306cecc60a36e859b041f6702c6a1ad9ead78924451`。比较范围为从 0.5 秒开始抽取并缩放至 320×180 的片段。

[UCI Air Quality](https://archive.ics.uci.edu/dataset/360/air+quality) 实测读取 9357 个小时。前 2000 小时标定，后段 5771 个共同有效时点用于比较。固定 Q=0.5、R=1 时，直接标定、卡尔曼滤波、离线 RTS 的 RMSE 分别为 0.785、0.898、0.933 mg/m³。平滑在此配置下增大了误差。

非平稳重尾变点练习使用合成 t 噪声、阶跃与孤立尖峰。定点二阶节在 x86 主机执行 C 参考代码。撤权练习在独立本地 HTTP 源站和代理上复现陈旧角色与缓存串读，再验证修正对照。
