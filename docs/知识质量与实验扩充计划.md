# 知识质量与实验扩充计划

## 知识内容复核

课程库有 68 门课、415 个已收录知识点的章节、2403 个知识点。六个专业模块共用数学与理论基础。所有条目均通过现有教学字段校验。该校验核对结构和来源链接格式。教学深度另行审阅。

短正文统计沿用上轮口径。只统计原理各段，先做 NFKC 归一化，再计字母、数字、加号和星号，少于 35 记作短正文。这条线用于排查。人工修订以适用条件、机制、例子和易错边界为准。

367 条短原理加入了具体讲解。18 道新增练习含逐步解析。3 组重合题干全部重写。两组保留原来的独立教学目标。第三组将受控中断的设置步骤集中在原课，另一个条目专讲报告指标和分母。保留原知识点 ID 和各原题的答案索引。

原先缺先修的 46 条中，25 条补上关系。其中有虚拟页接进程资源、KNN 接距离度量、查询计划接关系代数和 B+ 树。另 21 条经复核保留为相应课程的起点，例如补码、系统调用、集合关系和确立测试条件。先修全图检查了目标是否存在、是否重复及是否有环。

剩余 558 条集中在图形渲染对照、视频编解码对照、传感器融合回放及预测区间复核等既有专题。以核心教学目标继续复审，优先保留可迁移的图形学、状态估计和统计方法。逐条区分参考案例、纸笔推演和站内实验。

## 已有站内实验

| 模块 | 已注册且可执行 | 当前范围 |
| --- | --- | --- |
| 数据结构与算法 | 冒泡和快速排序、Dijkstra 和 A* | 排序统计比较和交换。寻路使用二维网格。 |
| 操作系统 | FCFS、时间片轮转 | 单 CPU 调度模型，输出等待与周转。 |
| 计算机网络 | 双路径传输和丢包 | 固定拓扑，按链路时延选路，带种子的逐跳丢包。 |
| 程序设计与内存 | 递归调用栈 | 仅执行固定阶乘程序，输出入栈和返回帧。 |
| 数据库原理 | B+ 树插入、分裂、点查和范围查询 | 小规模唯一整数键，沿叶链查询。 |
| 人工智能基础 | KNN | 二维样本，欧氏或曼哈顿距离，等权投票。 |

七个执行器均以同一入口实跑预设。比如两种寻路各得代价 5，两种排序都得到相同升序结果且比较次数为 21 和 14，KNN 结果为 A，票数为 2 比 1。15 个知识点仍关联已注册执行器。

## 外部环境实训

实机内核调度、真实分配器地址、联网拥塞压测、生产数据库并发和断电恢复都需要受控外部环境。现有站内执行器能演示这些场景中明确限定的算法模型。现场结果需由对应环境的实际观测给出。
